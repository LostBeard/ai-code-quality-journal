# AI Code Quality Journal

Real-world observations from a professional developer using AI coding tools in production — what works, what doesn't, and what to watch for.

## Why This Exists

I use AI coding assistants daily for complex .NET development: GPU compute transpilers, WebRTC peer-to-peer networking, ML inference engines, and browser-based applications. I pay for premium tiers because the work demands it.

This journal documents concrete, data-backed experiences — not opinions. Every entry includes actual code, test counts, and measurable outcomes. The goal is to help other developers make informed decisions and catch issues in their own AI-assisted workflows.

## What You'll Find Here

- **Audit reports** — Side-by-side comparisons of AI tool output quality on the same codebase
- **Anti-pattern catalogs** — Specific code quality failures with examples so you can grep your own projects
- **Practical guidance** — What to verify, what to watch for, and how to catch problems early

## Who I Am

Todd Tanner ([@LostBeard](https://github.com/LostBeard)) — I maintain several open-source .NET libraries including [SpawnDev.BlazorJS](https://github.com/nickkoskinen/nickkoskinen), [SpawnDev.ILGPU](https://github.com/nickkoskinen/nickkoskinen), and SpawnDev.WebTorrent. I work with AI tools extensively and consider them genuine collaborators in my workflow. These reports come from a place of wanting the tools to be better, not tearing them down.
